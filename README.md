# Rajasekhar Reddy Mekala — Personal Website (`rajasekharmekala.github.io`)

Zero-build, static HTML/CSS personal website styled in the unified Techmeme / Morning Brief theme (`site.css`).

## Structure
- `index.html`: Biography, active research portals, selected publications & patents, featured systems, and news milestones.
- `cv/index.html`: Complete Curriculum Vitae (Education, Adobe & UC Irvine Experience, Publications, Patents, Teaching, Honors & Awards, and Skills).
- `publications/index.html`: Complete bibliography and invention disclosures (`2019`–`2026`) with expandable abstracts and BibTeX.
- `projects/index.html`: Production AI systems (`Brand Concierge / BCOS`), research projects (`EchoPrompt`, `SNOOPY`, `SHERLOCKED`), and web applications (`PageRank`, `2048`).
- `repositories/index.html`: Live GitHub Pages portals and open-source repositories.
- `assets/pdf/` & `assets/img/`: CV/Resume PDFs, paper PDFs, and project/profile images.
