Brand Concierge (BCOS) — Enterprise Multi-Tenant LLM Agent Orchestrator, Grounded Neural Retrieval & Automated Program Optimization at Adobe

Adobe Inc. • Importance: 1
0→1 enterprise agentic application at Adobe. Joined roughly a month after initial ideation and led most foundational PoCs and technical spikes from prototype to production across the multi-tenant agent runtime, grounded neural retrieval/CPU inference, and automated agent optimization.
  • Unified Agent Orchestration (BCOS): Replaced multi-hop legacy pipelines with a single PydanticAI agent runtime supporting declarative manifest compilation and Agent-to-Agent (A2A) JSON-RPC protocols.
  • Deterministic Tool & Capability Layer: Designed extensible Pydantic tool schemas with declarative pre/post execution hooks, state capture primitives, and configurable error-recovery policies (ToolErrorPolicy).
  • Grounded Neural Source Attribution: Built a factory-based citation engine integrating cross-encoder rerankers (bge-reranker-v2-m3, e5-curriculum) with score normalization, <512-token truncation safeguards, and dynamic batching across enterprise pilots (NVIDIA, Synopsys, ITC, DSG).
  • CPU-Only ONNX Inference (Lucid Lens): Eliminated Candle batching limits by building CPU Text Embeddings Inference (TEI) services on ONNX Runtime with dynamic axes—reranking 30+ candidate passages in a single batch at 588ms–796ms p50 latency.
  • Automated Agent Optimization: Integrated Genetic-Pareto Prompt Optimization (GEPA) and DSPy into Eval Studio for reflective prompt compilation, achieving Pareto-optimal mutations with 35x fewer rollouts than RL baselines.
  • Streaming Serving & Multi-Tenant Isolation: Hardened the FastAPI/MongoDB conversation engine with SSE token streaming, artifact state replacement (StreamEventProcessor), and tenant sandbox isolation (TrafficControlEnforcer), plus a local FastEmbed semantic routing cache for sub-millisecond Q&A lookups.

EchoPrompt (NAACL 2024) — Instructing the Model to Rephrase Queries for Improved In-Context Learning and Chain-of-Thought Reasoning

UC Irvine NLP Lab • Importance: 2
EchoPrompt is a simple yet effective approach that prompts language models to rephrase their queries before answering them. Published in Findings of NAACL 2024 with Yasaman Razeghi and Dr. Sameer Singh at UC Irvine.
  • Evaluated across four causal language model families on numerical reasoning (GSM8K, SVAMP), reading comprehension (DROP), and logical reasoning tasks.
  • Improves Zero-Shot-CoT accuracy on code-davinci-002 by 5% on numerical reasoning and 13% on reading comprehension.
  • Demonstrates that both the original query and the model-generated rephrased version provide complementary semantic signals that stabilize in-context learning.
