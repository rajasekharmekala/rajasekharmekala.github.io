Brand Concierge (BCOS) — Enterprise Multi-Tenant LLM Agent Orchestrator, Grounded Neural Retrieval & Automated Program Optimization at Adobe

Adobe Inc. • Importance: 1
Adobe Brand Concierge (BCOS) is an enterprise Generative AI and multi-agent platform powering conversational brand experiences for global enterprises (including NVIDIA, Synopsys, ITC, and Dick’s Sporting Goods).
  • Agent Orchestration Engine (BCOS): Architected the unified PydanticAI agent runtime with declarative manifest compilation, replacing multi-hop legacy services with a single high-performance agent runtime supporting Agent-to-Agent (A2A) JSON-RPC protocols.
  • Declarative Tool Framework: Designed extensible Pydantic tool schemas with declarative pre/post execution hooks, state capture primitives, and configurable ToolErrorPolicy for deterministic runtime recovery.
  • Neural Source Attribution: Engineered a factory-based source attribution engine with remote cross-encoder rerankers (BGE-M3, E5-curriculum), client-side normalization, and token safeguards (<512 tokens), delivering grounded citation without hallucinations.
  • High-Performance Inference (Lucid Lens): Developed CPU-only Text Embeddings Inference (TEI) microservices on ONNX Runtime (ORT) with dynamic axes, eliminating Candle batching limits to rerank 30+ candidate passages in a single batch with sub-second p50 latency (588ms–796ms).
  • Automated Agent Optimization (Eval Studio): Integrated Genetic-Pareto Prompt Optimization (GEPA) and DSPy into Eval Studio, achieving Pareto-optimal prompt mutations with 35x fewer rollouts than RL baselines.
  • Streaming Serving & Traffic Isolation: Hardened core FastAPI/MongoDB conversation engine with Server-Sent Events (SSE) token streaming, artifact state replacement (StreamEventProcessor), and sandbox isolation (TrafficControlEnforcer).

EchoPrompt (NAACL 2024) — Instructing the Model to Rephrase Queries for Improved In-Context Learning and Chain-of-Thought Reasoning

UC Irvine NLP Lab • Importance: 2
EchoPrompt is a simple yet effective approach that prompts language models to rephrase their queries before answering them. Published in Findings of NAACL 2024 with Yasaman Razeghi and Dr. Sameer Singh at UC Irvine.
  • Evaluated across four causal language model families on numerical reasoning (GSM8K, SVAMP), reading comprehension (DROP), and logical reasoning tasks.
  • Improves Zero-Shot-CoT accuracy on code-davinci-002 by 5% on numerical reasoning and 13% on reading comprehension.
  • Demonstrates that both the original query and the model-generated rephrased version provide complementary semantic signals that stabilize in-context learning.
